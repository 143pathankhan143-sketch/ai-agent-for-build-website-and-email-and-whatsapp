# Freshy AI — Local AI Web Agency

Desktop-first, Hindi/English workflow for researching business leads, building concept websites, and preparing human-approved outreach.

**Current status: planning only.** No runnable agent, live discovery provider, email sending, or WhatsApp integration has been implemented yet.

## Start here

1. [Complete project blueprint (Hindi + English)](docs/PROJECT_BLUEPRINT.md)
2. [Step 01: Computer and Python setup check](docs/STEP_01_SETUP.md)

## Planned approach

- Local Python dashboard and SQLite database; no mandatory paid service.
- Manual/CSV leads first; permitted discovery integrations later.
- Source-backed facts and human review before website generation.
- HTML/CSS/JS output first; React export in a later phase.
- Separate approvals for website, public publishing, and each outreach message.
- Draft/manual-send workflow first; official live-channel integrations only after configuration and policy review.
- No bulk Maps scraping, WhatsApp-number probing, fabricated business facts, or unapproved outreach.

Generated sites are unofficial concept demos until the business authorizes them. Public contact information is not blanket permission for marketing. Optional cloud providers, messaging, domains, and AI models may have costs or resource requirements.
